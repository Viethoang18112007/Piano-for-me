# Đàn Piano Python

Ứng dụng đàn piano đơn giản được tạo bằng Python và Pygame.

## Cài đặt

1. Cài đặt Python (nếu chưa có)
2. Cài đặt pygame:
```bash
pip install -r requirements.txt
```

hoặc

```bash
pip install pygame
```

## Chạy chương trình

```bash
python piano.py
```

## Cách sử dụng

### Chơi bằng bàn phím:
- **Phím trắng**: A, S, D, F, G, H, J, K, L
- **Phím đen**: W, E, T, Y, U, O

### Chơi bằng chuột:
- Click vào các phím trên màn hình để chơi nốt nhạc

## Tính năng

- Giao diện đàn piano với phím trắng và đen
- 2 octaves (14 phím trắng)
- Phát âm thanh thực tế cho mỗi nốt nhạc
- Hỗ trợ chơi bằng bàn phím và chuột
- Hiển thị tên nốt nhạc trên mỗi phím

## Thoát chương trình

Nhấn nút X ở góc cửa sổ hoặc đóng cửa sổ.
